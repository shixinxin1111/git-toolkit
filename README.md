# Git 工具箱

`Git 工具箱` 是一个 VS Code 插件，在内置的源代码管理面板中集中展示本地忽略记录、本地分支和远程分支。

## 功能

### 本地忽略

- 在资源管理器或源代码管理面板中右键忽略已被 Git 跟踪的文件
- 使用 Git 的 `skip-worktree` 标记，不修改仓库中的 `.gitignore`
- 取消忽略后保留置灰记录，可快捷重新添加
- 删除记录时恢复 Git 跟踪并从列表中移除
- 记录按工作区持久化

### 分支

- 展示当前工作区 Git 仓库中的全部本地分支
- 当前分支始终排在首位，并在右侧显示双圈标记
- 其他分支按名称字典序排列
- 可在完整分支列表和按 `/` 路径折叠的树形结构间切换
- 显示最后一次提交的相对时间
- 有同步差异时显示 `远程领先数↓ 本地领先数↑`
- 展开分支查看最近 10 条提交，并可继续每次加载 10 条
- 本地领先显示绿色、远程领先显示红色、双方均有更新显示黄色
- 一键获取远程更新并安全快进所有可更新的本地分支
- 悬浮本地分支时可直接拉取上游或检出该分支
- 本地领先时，行内拉取按钮自动切换为推送
- 监听 Git 仓库状态，提交后自动刷新分支与同步颜色
- 右键可将所选分支合并到当前分支，或将当前分支变基到所选分支
- 右键可重命名、安全删除或强制删除本地分支
- 右键可将本地分支对应的 upstream 加入远程收藏
- 右键可复制分支名或生成 `x-fe-env` 泳道信息
- 多工作区中同时展示多个仓库的分支
- 使用紧凑的原生侧边栏布局平铺展示

### 远程

- 展示本地 Git 仓库已知的全部远端分支
- 按 `origin`、`upstream` 等远端名称分组
- `origin` 等远端节点始终保留，其内部可切换完整列表或按 `/` 路径折叠的树形结构
- 收藏或取消收藏远程分支
- 点击标题栏星标直接切换全部/收藏范围
- 在 `origin` 等远端节点右侧直接获取该远端
- 悬浮分支时可直接收藏或检出
- 右键可将当前分支变基到所选远程分支
- 右键可从远程仓库删除所选分支
- 检出时自动创建并切换到去掉远端前缀的同名本地分支
- 显示最后一次提交的相对时间
- 展开分支查看提交历史，每次加载 10 条
- 一键执行 `git fetch --all --prune` 更新所有远程
- 收藏和展示范围按工作区持久化

## 使用方式

安装后，打开 VS Code 自带的 `源代码管理` 面板，向下可以看到：

- `分支`
- `远程`
- `本地忽略`

三个视图使用 `标题 · 数量` 的形式展示数量。远端名称作为可折叠目录，悬浮远程分支时会显示收藏和检出按钮。

### 刷新与更新

- `刷新`：只重新读取本地 Git 数据并刷新列表，不访问网络，也不修改分支。
- `更新所有远程`：执行 `git fetch --all --prune`，从网络更新远程引用。
- `更新所有本地分支`：先获取远程更新，再安全快进单纯落后的本地分支；本地领先或已分叉的分支会跳过。

## 说明

- 远程分支来自当前仓库已有的 `refs/remotes`；只有点击更新按钮时才会执行 `git fetch`。
- “更新所有本地分支”只会快进单纯落后于远程的分支，不会覆盖本地领先或已分叉的分支。
- 本地忽略仅支持已被 Git 跟踪的普通文件；未跟踪文件应使用 `.gitignore`。
- `skip-worktree` 是本地索引标记，不等同于 `.gitignore`。切换分支、合并或执行部分 Git 索引操作时，Git 仍可能要求先处理本地修改。
- 插件只展示由自身创建的本地忽略记录，不会扫描其他工具设置的 `skip-worktree` 标记。

## 开发

```bash
pnpm install
pnpm test
```

在 VS Code 中打开本目录并按 `F5`，即可启动扩展开发宿主。
